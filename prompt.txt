
Portfolio Website Redesign PRD
Project Background
This is a personal portfolio website designed as an interactive tree-world inspired by Rusty Lake's Family Tree aesthetic.
The portfolio is intended for applications in:
- Brand Growth
- Growth Marketing
- User Research
- Marketing
- Operations
The core theme of the website is:
"A collection of stories, observations and experiments."
The website should communicate:
This person is someone who continuously observes people, understands behavior, and transforms insights into content, community, marketing and growth.
Global Design Principles
Atmosphere
Maintain the existing illustrated, storybook-like visual style.
Do NOT redesign into a corporate portfolio.
The experience should feel like exploring a personal archive.
Keywords:
- Curious
- Warm
- Reflective
- Exploratory
- Human-centered

---
Homepage Redesign
Hero Experience
When the page loads:
Stage 1
Tree remains completely static.
No glowing elements.
Wait ~1.5 seconds.
Stage 2
The red bird performs a subtle hop animation.
Stage 3
Near the bird, fade in text:
"Choose a path."
Text should appear gradually.
Handwritten or storybook style preferred.
Stage 4
Three picture frames and the treasure chest begin a very subtle glow animation.
The glow should be gentle and slow.
Avoid flashy effects.
Goal:
Guide visitors toward exploration.

Treasure Chest Page
Purpose:
Answer the question:
"What am I exploring now?"
The treasure chest should NOT open into a file list.
Instead:
Open into an Explorer's Collection scene.
Display collectible objects.
Examples:
Scroll → Overseas Drama Marketing Plan
Compass → Home Appliance Marketing Plan
Wood Artifact → Furniture Mall Marketing Plan
Potion Bottle → AI Video Project
Crystal Fragment → AI Observation Notes
Notebook → Interview Assignments
Each object is clickable.
When clicked:
Display:
- Cover
- Summary
- Preview image
- Link to full content
Support:
- PPT
- HTML pages
- Videos
- PDFs
Technical Requirements
- Responsive design
- Mobile-friendly
- Smooth transitions
- Lazy loading for images
- Expandable cards
- Modular content structure
- Easy future content addition
Future content should be configurable via JSON or data objects rather than hardcoded HTML.
